# IQ4EV Website

Public website for IQ4EV (Pty) Ltd — Strategic EV Data & Consulting.

## Purpose

The website presents IQ4EV as a South African EV intelligence company focused on:

- EV infrastructure intelligence
- Charger and property visibility through Pulse360
- Spatial planning intelligence through TerrainIntel
- Fleet simulation and readiness through EVSS
- Strategic EV consulting
- Public insights and enterprise briefings

## Tech Stack

- React
- Vite
- React Router
- Tailwind CSS
- Lucide React
